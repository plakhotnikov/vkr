# Дневник работы над ВКР

Один файл `YYYY-MM-DD.md` на день работы по местному времени пользователя. Дни без работы пропускаются. Дневник ведётся по поручению от 15.11.2026.

## Что записывать

- Цель дня и задача из [плана спринтов](../planning/sprints.md).
- Выполненная работа и находки со ссылками на источники и результаты.
- Проверки и их результаты.
- Принятые решения, предложения и открытые вопросы.
- Следующий шаг и блокеры.

Дополнять запись в течение дня, сохраняя изменения решений. Не выдавать оценки времени за замеры, а черновики за согласованные тексты. Секреты, личную переписку и служебный вывод не сохранять. Исходники экспериментов хранить отдельно и давать ссылки.

Использовать [шаблон](TEMPLATE.md), после сессии обновлять статусы плана. Дневник ВКР ведётся отдельно от предметного `../logs.md`.
