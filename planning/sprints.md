## Как отслеживать работу

Статусы: `запланировано`, `в работе`, `подготовлено`, `проверено`, `согласовано`, `заблокировано`. Выполнение подтверждается результатом и проверкой: описание алгоритма не заменяет код, обзор документации не заменяет запуск. После работы обновляются план и [дневник](../journal/README.md).

Раз в две недели готовится отчёт: цель, результаты, проверки, ограничения, следующий шаг. Работа разбита по неделям. Первый отчёт назначен на 16.11; остальные даты предложены по тому же ритму.

## Условия завершения следующего спринта

- [ ] Demo воспроизводимо запускается в Kubernetes с закреплёнными версиями.
- [ ] Выбранный сбой внесён и снят, нагрузка и временные окна записаны.
- [ ] Получены реальные логи, метрики, трассы и каталог сервисов; сопоставления проверены.
- [ ] Проверены MCP-клиент, сервер, вызов провайдера и один LLM-запрос без скрытых повторов.
- [ ] Для принятого задания определён путь интеграции Prometheus/Alertmanager, Loki, Tempo; временный штатный backend не выдаётся за выполненную интеграцию.
- [ ] Есть сохранённый корпус и начальное воспроизведение разрешённых запросов.
- [ ] Измерены технические затраты, записаны ограничения; подготовлен отчёт к 30.11.
