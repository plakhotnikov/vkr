- [4.2. Формализация](docs/4.2-formalization.md): инцидент, модели телеметрии, граф, сигналы, ответ, лимиты.

- [4.8. Оценка](docs/4.8-evaluation.md): сценарии, метрики, подбор настроек, план эксперимента, графики.
- [Журнал решений](docs/decisions.md): что решили и почему; что проверить в спринте 2.
