# Материалы первого спринта

Документы к отчёту 16 ноября 2026 года охватывают пункты 4.2 и 4.4 задания. Начать чтение можно с [краткого отчёта](reports/2026-11-16-sprint-0.md), затем перейти к постановке задачи, алгоритмам и оценке.

| Материал | Что содержит |
| --- | --- |
| [Постановка задачи, пункт 4.2](design/problem-formalization.md) | Вход и результат, модели телеметрии, нормализация, граф, отбор контекста и ограничения |
| [Алгоритмы, пункт 4.4](design/diagnostic-algorithms.md) | Общая подготовка, однократная и пошаговая диагностика, псевдокод, схемы Mermaid |
| [Методика оценки](evaluation/methodology.md) | Проверяемые предположения, сценарии, метрики, повторения и сравнение на одинаковых данных |
| [HolmesGPT](research/holmesgpt.md) | Возможности аналога, источники и пересечения с темой ВКР |
| [Техническая основа](research/technical-foundation.md) | Состав OpenTelemetry Demo, варианты интеграции и проверки следующего спринта |

Mermaid-схемы находятся прямо в Markdown: подготовка данных в постановке задачи, взаимодействие компонентов и две блок-схемы в алгоритмах. GitHub отображает их при просмотре файлов.

[Недельный план](../planning/sprints.md) хранит задачи и текущие статусы. [Дневник](../journal/README.md) хранит результаты каждого рабочего дня. Это рабочие версии для обсуждения; результаты реализации и экспериментов будут добавляться по факту.
