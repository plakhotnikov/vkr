## Формализация (4.2)

7. **Инцидент = группа алертов из webhook.** Окно $W$ и базовое $B$. Запуск по webhook или вручную. Окно фиксируется при запуске — повторы видят те же данные.
8. **Четыре типа записей + общий заголовок $(s, \rho)$.** События K8s — отдельный тип: деплой и OOM.
9. **Набор метрик в конфиге, заморожен в серии.** Снимок конфигурации на каждый запуск. *Уточнено:* сначала было «фиксированный» — это значит «одинаковый в серии», не «зашит в код».
10. **Рёбра графа — только из трассировок.** K8s API даёт вершины, не рёбра.
11. **`TopologyProvider`: граф сервисов | статический | нет графа.** *Пересмотрено:* своя агрегация спанов убрана — дублирует `servicegraph` в Collector.
12. **Работа без графа — ось эксперимента и проверка п. 4.7** (недоступный источник).
13. **Сигналы с баллом странности.** Медиана/MAD для метрик, Drain для логов.
14. **Фильтрация — не набор вариантов, а «есть / нет».** *Уточнено:* полный перебор вариантов умножает число запусков; ось с двумя уровнями.
15. **Настройки подбираются без LLM** на тренировочных сценариях: попал ли виновник в топ-5.
16. **Ответ: топ-3 гипотезы.** Под AC@1 и AC@3.
17. **Причина — ~8 групп + подтип своими словами.** *Обсуждено:* 30 групп пересекаются и не покрываются 15–20 сценариями.
18. **Лимит контекста = сумма входных токенов по всем запросам.** Пошаговая шлёт историю заново.
19. **Входные токены ограничиваем сами, `max_tokens` — только длина ответа.** Факт — из `usage`.
20. **Общий LLM-прокси для всех, включая HolmesGPT.** Одна линейка.
21. **Время: медиана и разброс, запуски вперемешку, сбор данных отдельно от LLM.** Выводы о затратах — по токенам.

## Алгоритмы (4.4)

22. **Подозреваемые: «самый глубокий странный»** по графу. Без графа — по странности.
23. **Стратегия «только правила» (S1)** — сколько даёт LLM поверх правил.
24. **Упаковка — жадно по «польза ÷ вес»** с гарантией сигнала на подозреваемого. Задача о рюкзаке.
25. **JSON по схеме, номера сигналов, мин. температура, шаблон с версией.** Сломанный JSON — неудачный запуск.
26. **Температура и шаблон не сравниваются.** Шаблон правим на тренировочных, потом заморозка.
27. **Ссылки: существует / по теме — авто; подтверждает — инженер.** Гипотезы только помечаем.
28. **Агент с полным доступом: PromQL, LogQL, TraceQL, K8s.** *Пересмотрено дважды:* сначала «только наши инструменты», потом «LogQL с ограждением». Итог: связанный агент — нечестно слабый противник; сравнение и так меряет цену свободы. Остались: только чтение, окно ≤ $W$, обрезка огромного.
29. **Агент стартует со сводки S4.** Разница S4 → S5 = польза шагов. Отличие от HolmesGPT измеримо.
30. **Гипотезы на каждом шаге.** Протокол и кривая по шагам.
31. **Остановка: `final_answer` | лимит | 3 шага без изменений.** Причина — в протокол.
32. **Рекомендации от LLM к каждой гипотезе: «проверить» | «исправить» + ссылки.** Эталонные действия — в карточке заранее.

## Оценка (4.8)

37. **Затраты: токены главная мера. Деньги — одной фразой.**
38. **Главный график AC@1 ↔ токены + кривая по шагам.**

## После сверки с первоисточниками (16.11)

39. **RCAEval-агенты частично пересекаются с вопросом «качество ↔ затраты».** Там уже есть AC@k рядом с токенами и стоимостью. Ниша сужена: живой стек вместо записанных случаев; однократная стратегия с упаковкой по графу; лимит контекста как ось, не как защита; кривая по шагам; группа причины, рекомендации, проверка ссылок, оценка инженером. Подробно — [4.1](4.1-analogs.md).
40. **AIOpsLab: лимит только по шагам, оценка без инженера.** Отграничение из п. 4 подтверждено.
41. **Внешняя проверка S1–S5 на RE2 / RE3 RCAEval.** Защита от подгонки под свой стенд; сравнение с опубликованными цифрами RCAEval. Файловый провайдер — заодно пример расширяемости (п. 4.7).

## Уточнение фильтрации (16.11)

42. **Балл сигнала всегда 0–1.** Метрики: $\min(1, \lvert z \rvert / 2\theta)$; логи и спаны — по росту «во сколько раз» через $\log_2$; события K8s — веса из конфига. Иначе сигналы разных типов не сравнить при упаковке.
43. **Счётчики сравниваем в минуту.** $W$ и $B$ разной длины.
44. **Новая настройка $k$ и веса событий K8s.** Подбор вместе с остальными ([4.8](4.8-evaluation.md), раздел 4).
